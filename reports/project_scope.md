# South African Data & Technology Job Market Analysis

## 1. Project Overview
This project investigates the demand for data and technology skills in the South African job market through the analysis of publicly advertised job opportunities.

## 2. Project Purpose
The purpose is to identify in-demand technical skills, understand employer requirements, explore entry-level opportunities and examine trends in job categories, qualifications, experience requirements and work arrangements.

## 3. Geographic Scope
- Primary focus: South Africa.
- Includes remote opportunities available to South African applicants.
- Includes on-site, hybrid and remote positions.

## 4. Job Categories
- Data Analytics
- Data Engineering
- Data Science
- Business Intelligence
- Database-related roles

## 5. Target Sample Size
- Minimum: 20 job advertisements.
- Initial target: 30 job advertisements.
- Stretch goal: 50 job advertisements.
- Longer-term target: 30–100 advertisements.

## 6. Data Collection Period
18 November 2026 onwards. The collection period and dates accessed will be documented as data is gathered.

## 7. Data Sources
Potential sources include LinkedIn Jobs, PNet, Careers24, Indeed and company career websites.

## 8. Technologies
- SQL and PostgreSQL
- Python
- Pandas
- Jupyter Notebook
- Power BI
- Git and GitHub

## 9. Expected Outcomes
The project aims to produce a structured dataset, documented data cleaning process, SQL analysis, Python exploratory data analysis, an interactive Power BI dashboard and a findings report.

## 10. Limitations
The findings will reflect the advertisements collected and will not necessarily represent the entire South African job market. Missing information, sampling bias and differences between recruitment platforms will be considered when interpreting results.
